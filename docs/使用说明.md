# 使用说明

启动项目后访问 `http://127.0.0.1:8765`。当前版本只有“行情与指标”单页研究工作台。

## 基本操作

1. 在创业板指数和纳斯达克 100 指数之间切换。
2. 默认查看周 K，也可以切换日 K 和月 K。
3. 价格、成交量、MACD 柱、DIF/DIP、DEA/EDA 位于同一个图表，并共享时间轴、缩放和十字光标。
4. 点击“刷新指数数据”更新直接指数行情。创业板周/月成交量在上游失败时由日成交量聚合；NDX 不用 ETF 成交量代替。
5. 在“投资日历”记录指数仓位的增加或减少。变化百分比必须是 5% 的整数倍，保存后可修改或两步确认删除。
6. 页面会从本地数据库恢复历史仓位，并自动计算两个指数各自的当前仓位。

## 数据分析

设置当前指数仓位后点击“数据分析”：

- 浏览器向本地 FastAPI 后端创建任务；
- 后端不调用 Agent 或 AI；
- 第一次执行会覆盖十年内每个唯一完整交易周，通常约 520 次；
- 第 `n` 次继承第 `n-1` 次的 W 状态；
- 每出现一个新完整交易周，后续点击最多增加一次迭代；
- 同周重复点击不增加 I/W/M，只按最新仓位重新生成建议。

任务区会显示阶段、完成周数、I/W/M、最后检查点和耗时。完成后显示：

- 未来 13 周上涨、下跌或震荡判断；
- 概率和置信度；
- 当前仓位与目标仓位；
- 最多 4 批的预期日期、±3 个交易日容差、买卖百分比和确认条件；
- 五档基金/ETF 配置；
- 单次、20 次和 52 次偏离、方向命中、校准误差、候选接受率与改善曲线。

所有买卖百分比均为 5 的倍数。若没有设置当前仓位，系统只显示市场分析，不生成具体买卖比例。

## 数据位置

- 行情、仓位、任务、模型和建议：`data/investment_lab.db`
- V2 JSON 审计：`data/weekly_analysis_v2/`
- 备份：`data/backups/`

旧 V1 模型目录 `data/model_iterations/399006/` 和 `data/model_iterations/NDX/` 只读保留，不参与网页 V2 分析。
