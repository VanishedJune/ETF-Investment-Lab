# 投资研究台 V3.2 模型协议

## 1. 运行边界

V3.2在本地后端运行，不调用Agent、LLM、Codex或外部AI服务。运行时只包含直接指数行情刷新、确定性特征计算、历史相似路径预测、递进参数优化和本地持久化。

只研究两个相互独立的市场：

- 创业板指数 `399006`；
- 纳斯达克100指数 `NDX`。

## 2. 训练与预测分离

“训练模型”负责产生或更新模型；“数据分析”只加载最新Champion做纯推理。数据分析前后，`v32_training_iterations`数量、模型版本和优化器状态必须完全一致。

## 3. 首次历史训练

首次交付对实际十年窗口内每一个完整交易周执行一次正式迭代。迭代次数由交易所日历决定，不固定为100、480或500。包含第五个自然周的月份按实际完整周执行第五次。

每轮必须：

1. 继承上一轮Champion参数与优化器记忆；
2. 只读取该截点以前可见的完整周K；
3. 截取该截点可见的最近100个日K交易日作为修正特征；
4. 只匹配在截点前已经完整成熟13周的历史窗口；
5. 生成连续13周P10、P50、P90和期望收益路径；
6. 保存预测、样本外评价、候选参数、晋级/拒绝原因和检查点。

最后13轮没有完整未来13周结果，状态必须为`pending`，指标为空，不得填0、插值或连接空白。

## 4. 递进优化与晋级

模型使用带权历史相似路径。周K特征包括4/8/13周收益、13周波动率、20周均线距离、MACD差、估值分位和60周回撤；日K特征包括5/20日收益、RSI、20日均线距离、MACD差和20日波动率。

Challenger只对上一轮参数作受限坐标调整。晋级依据最近52个成熟样本和最近20个成熟样本的真实样本外比较，同时约束方向评分与P10-P90覆盖率。未通过的候选及其原因仍写入下一轮优化器记忆。

综合损失由以下真实评价组成：

- 35%：13周路径误差；
- 15%：分位越界和覆盖率误差；
- 15%：第13周终点误差；
- 15%：上涨/震荡/下跌概率评分；
- 10%：阶段高低点时间偏差；
- 10%：预测仓位与事后最优仓位偏差。

## 5. 后续每周训练

首次训练完成后，启动程序或点击训练按钮先判断：

- 是否出现新的完整交易周；
- 距上次成功训练是否至少7天。

两个条件同时满足时，每个市场最多新增一次迭代。即使离线跨越多个周，也只新增一次，并记录跳过周数。相同完整周重复启动或点击保持幂等。

## 6. 数据分析

数据分析按以下顺序执行：

`刷新直接指数数据 → 数据门禁 → 加载最新Champion → 周K预测 → 100日日K修正 → 13周概率路径 → 读取当前仓位 → 分批建议 → 持久化分析审计`

未记录仓位时按清仓`0%`处理。目标仓位及每批调整均为5个百分点的倍数。基金与ETF比例只能是`7:3`、`6:4`、`5:5`、`4:6`或`3:7`。

关键日K过期、最近交易日缺口、异常OHLC或替代/演示数据会阻断建议。估值缺失允许降级运行，但必须显示来源和缺失状态，不得填0。

## 7. 可审计持久化

V3.2使用以下表：

- `v32_training_runs`
- `v32_training_iterations`
- `v32_training_checkpoints`
- `v32_model_versions`
- `v32_optimizer_states`
- `v32_data_snapshots`
- `v32_weekly_forecasts`
- `v32_daily_corrections`
- `v32_model_evaluations`
- `v32_analysis_runs`
- `v32_app_state`

旧V1/V2/V3.1表和JSON审计目录保持只读留存。
