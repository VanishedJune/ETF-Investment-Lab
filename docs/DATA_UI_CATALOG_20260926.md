## 日线和周线涨跌幅

- 日：当前未复权收盘价 / 上一实际交易日收盘价 - 1。
- 周：本周最后可用收盘价 / 上一周收盘价 - 1。
- 周内预览明确显示本周截至当前；价格日期与技术指标日期不同时分别提示。
- 缺前一期、缺价格、非正价格、日期逆序不显示有效收益。
- 这是价格涨跌幅，不包含分红再投资和用户持仓盈亏。
