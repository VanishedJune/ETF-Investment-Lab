双市场投资研究台 V3.3-20W（Windows 桌面版）

1. 双击 InvestmentLab.exe 即可打开内嵌窗口，不需要启动服务器或输入网址。
2. 程序资源与可写数据分离：数据库、训练检查点、仓位日历和历史分析位于程序同目录的 data 文件夹，配置位于 config 文件夹。
3. V3.3 的两个活动目标是创业板指数 399006 和广发纳斯达克100ETF 159941；NDX 只作为 159941 的底层基准和 V3.2 只读审计对象。
4. “训练模型”与“数据分析”相互独立。数据分析只加载最新 Champion，不会增加训练轮次、修改模型或修改优化器。
5. 首次交付需对实际十年窗口的每个完整自然周完成一轮递进训练；后续只有出现新完整周且距上次成功训练至少 7 天时，每个市场最多新增 1 轮。159941只使用2015-07-13上市后的真实ETF数据，不以NDX或其他ETF补历史；模型会在真实样本不足标准窗口时明确标记降级状态。
6. 预测为未来 20 周 P10/P50/P90/expected 概率路径；最新 20 轮没有完整结果时保持 pending 和空评价，不用 0 填充。
7. 当前仓位来自本地投资日历，未记录时按 0% 清仓状态处理。目标和每批调整均为 5 个百分点的倍数；基金/ETF 配比只使用 7:3、6:4、5:5、4:6、3:7。
8. 创建或恢复备份前先关闭主程序，再运行“Create-Data-Backup.bat”或“Restore-Data-Backup.bat”。
9. 如程序提示缺少 Microsoft Edge WebView2 Runtime，请安装 Evergreen Runtime 后重试。
10. 本工具仅用于研究，不连接券商、不自动交易，结果不构成收益承诺或确定性投资建议。
11. 正式发布在打包前执行V3.2冻结审计和V3.3模型状态审计；同目录“V3.3-model-state-audit.md”记录自然周轮次、父哈希链、最后20轮pending和分析纯推理证据。

完整协议见同目录“V3.3-MODEL-PROTOCOL.md”。

系统要求：Windows 10/11 64 位、Microsoft Edge WebView2 Runtime、刷新公开数据时需要可用网络连接。
