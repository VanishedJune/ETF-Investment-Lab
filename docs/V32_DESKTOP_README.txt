双市场投资研究台 V3.2（Windows桌面版）

1. 双击 InvestmentLab.exe 即可打开，不需要手动启动服务器或输入网址。
2. 程序和数据分离：investment_lab.db、训练检查点和历史记录位于同目录的 data 文件夹。
3. “训练模型”与“数据分析”相互独立。数据分析只使用最新Champion，不会增加迭代次数。
4. 首次交付已完成创业板指数与纳斯达克100指数的完整十年递进训练。
5. 后续只有出现新的完整交易周且距上次成功训练至少7天时，每个市场才新增最多1次训练。
6. 创建或恢复备份前先关闭主程序，再运行“创建数据备份.bat”或“恢复数据备份.bat”。
7. 本工具仅用于研究，不连接券商，不自动交易。

系统要求：Windows 10/11 64位、Microsoft Edge WebView2 Runtime、可用网络连接（刷新行情时）。
