# 投资助手 V3.1 本地模型协议

V3.1 是网页“数据分析”按钮触发的确定性本地后端流程，不调用 Agent、LLM 或外部 AI 服务。V2 继续作为只读对照基线，V1 审计目录继续只读保留。

## 一次分析的固定顺序

`刷新直接指数行情 → 校验数据 → 选择最近完整周K → 计算周K主信号 → 截取最近100个交易日日K → 计算日K修正 → 生成13周P10/P50/P90路径 → 读取仓位 → 生成条件化分批建议 → 持久化运行与预测`

无投资日历记录时，当前仓位按清仓状态 `0%` 处理。所有目标仓位和执行批次均按5个百分点取整。基金与ETF比例只允许 `7:3`、`6:4`、`5:5`、`4:6`、`3:7`。

## 数据边界

- 创业板和NDX分别计算最新可用交易日，考虑当地时区与收盘后发布时间。
- 周K主模型只读取当前自然周之前已经完整收盘的周K；当前周日K只进入日线修正和页面预览。
- 创业板周成交量优先使用上游周量，缺失时使用真实日成交量按周求和。
- NDX默认禁用含义不可靠的直接指数成交量特征，页面明确显示 `DISABLED_DIRECT_INDEX`。
- 估值缺失属于软降级并扣减置信度；关键日K过期、OHLC异常、近期交易日缺口、代理/演示数据等属于硬阻断。

## 模型职责

- `CYB_WEEKLY_V3.1.x` 与 `NDX_WEEKLY_V3.1.x` 独立保存参数、阈值和随机种子。
- `CYB_DAILY_CORRECTOR_V3.1.x` 与 `NDX_DAILY_CORRECTOR_V3.1.x` 每个预测截点只读取此前100个交易日。
- 日K置信度和仓位修正均限制在正负10个百分点，不能直接反转高置信度周K方向。
- 13周路径使用历史相似情景的完整连续路径计算逐周分位数，强制满足 `P10 <= P50 <= P90`。

## 预测与训练分离

每个完整交易周可以生成一次正式预测。同周重复点击不会创建第二个周预测，只会重新执行数据门禁并更新日线节奏和仓位建议。模型重新训练只能由独立候选评估流程触发；候选是否晋级取决于成熟样本的真实样本外路径误差、概率评分、覆盖率、换手和回撤，不取决于累计迭代次数。

13周预测在13周后完全成熟。页面最近20次、52次和全部指标只读取成熟预测，样本不足时显示“等待成熟样本”，不填0、不伪造改善。
